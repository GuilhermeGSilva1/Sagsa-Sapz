# SAGSA - Sistema Gerador de SAPZ
Alunos:
Guilherme Gonçalves da Silva e Brayan Gabriel Bittencourt de Oliveira

Projeto integrado de Backend em Spring Boot e Frontend para gestão de Situações de Aprendizagem (SAPZ).

## Como Executar no programa VSCode

1. Abra a pasta do projeto no **VSCode**.
  
3. Certifique-se de que o **MySQL** está rodando e a base de dados `sistema_sapz` foi criada a partir do script SQL.
   
5. Pressione `F5` para iniciar a API Spring Boot (ou execute via terminal `./mvnw spring-boot:run`).
   
7. Abra o arquivo `frontend/login.html` com a extensão **Live Server** (Porta 5500).
